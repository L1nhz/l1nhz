L1nh (@l1nhz) — Terminal Portfolio
===================================

Included files:
- index.html : Main portfolio webpage (all in English, Terminal style)
- avatar.jpg : Your custom avatar photo

How to publish on GitHub Pages:
1. Extract this ZIP file.
2. Create a public repository named: <your-github-username>.github.io
3. Upload index.html and avatar.jpg to the root of the repository.
4. Go to Settings -> Pages -> Deploy from branch: main / (root) -> Save.
